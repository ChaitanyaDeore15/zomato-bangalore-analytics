# Zomato Bangalore Dataset Storage

This directory manages dataset files for the **Zomato Bangalore Restaurant Analytics** project.

## Directory Structure

- `raw/`: Contains the original raw CSV dataset `zomato.csv`.
- `processed/`: Contains preprocessed and cleaned datasets generated by Apache Spark pipelines (both Parquet and CSV formats).

## Dataset Summary
- **Source**: Kaggle Zomato Bangalore Restaurants dataset (provided for college FA1 / FA2 Big Data Analytics activity).
- **File Name**: `zomato.csv`
- **File Size**: ~574 MB
- **Total Records**: 51,717 rows
- **Columns**: 17 attributes detailing restaurant metadata, ratings, votes, cuisines, locations, and pricing.
- **Geographic Coverage**: Greater Bangalore municipal & suburban zones.

## Placement Instructions
If running on a fresh environment, ensure `zomato.csv` is placed inside `data/raw/`:
```bash
# Verify raw data presence
ls data/raw/zomato.csv
```
The raw dataset is treated as immutable and is never modified in place. Cleaned datasets are written to `data/processed/` and aggregated analytical metrics are saved in `outputs/analysis_results/`.
